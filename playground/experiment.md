# Experiment brief

## Assignment

- Base commit and `codex/` branch
- Observed problem or profile evidence
- Hypothesis and predicted effect
- Files or pipeline stages in scope
- Primary metric, correctness criteria and reserved acceptance case
- Trial or compute budget and stop condition

## Worker evidence

- Candidate commit and summary of the change
- Dataset revision, environment, thread count and exact commands
- Baseline and candidate measurements for each repetition
- Numerical differences, failing or skipped checks, local artifact paths
- What the result supports or rules out

## Lead decision

- Independent rerun, acceptance case and result
- Keep, revise or reject, with reasoning
- Remaining limitations and the next question, if any
